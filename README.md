# 🐟 GoPowered
GoPowered is a Go-based language that compiles to Go.<br/>
It essentially adds certain features to it - e.g. `panicBasedErrorHandling()!` *(useful in tests)*.

## 🧺 Installation
1. Install the [NET SDK 10.0](https://dotnet.microsoft.com/en-us/download)
2. Download these 3 files:
- https://github.com/Olafcio1/GoPowered/raw/refs/heads/main/bin/Release/net10.0/GoPowered.exe
- https://github.com/Olafcio1/GoPowered/raw/refs/heads/main/bin/Release/net10.0/GoPowered.dll
- https://github.com/Olafcio1/GoPowered/raw/refs/heads/main/bin/Release/net10.0/GoPowered.runtimeconfig.json
  <br/><br/>
  And put them into a directory, e.g. called `GoPowered`.
3. Add that directory's path to your PATH environment variable
4. You can use `GoPowered run/build/dump ...` in your new terminal windows now
